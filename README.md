## Auf GitHub Pages veröffentlichen
1. Erstelle ein neues öffentliches GitHub-Repository.
2. Entpacke die ZIP-Datei.
3. Lade alle enthaltenen Dateien in die oberste Ebene des Repositorys hoch.
4. Öffne **Settings > Pages**.
5. Wähle unter **Build and deployment**: **Deploy from a branch**.
6. Wähle den Branch **main** und den Ordner **/(root)**.
7. Speichere und warte auf den GitHub-Pages-Link.

## Musik
- Über **Dateien laden** bleiben Musikdateien im Browser des jeweiligen Geräts gespeichert.
- Alternativ kannst du eigene Musik in den Ordner `musik` laden und über ihre direkte GitHub-Raw-URL hinzufügen.
- Lade nur Musik hoch, für die du die nötigen Rechte besitzt.

## JBL-Boxen
Eine Webseite kann Bluetooth-Audioausgänge nicht selbst koppeln. Verbinde eine Box über die Bluetooth-Einstellungen und weitere kompatible Boxen direkt über PartyBoost, Connect+ oder Auracast.
